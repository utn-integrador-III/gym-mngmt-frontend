# Gym Management Frontend

This is the frontend of the Gym Management application, built with **React** and **TypeScript**. It allows trainers and clients to interact with workout routines, track progress, and manage user information.

## 🚀 Tech Stack

- React
- TypeScript
- Vite
- React Router DOM
- Axios

## 📦 Installation

1. Clone the repository:

```bash
git clone https://github.com/utn-integrador-III/gym-mngmt-frontend.git
cd gym-mngmt-frontend

2. Install dependencies

### npm install
### npm install react-router-dom
### npm install @fortawesome/fontawesome-free

### `npm start`

### instalar dependencias necesarias de react-scripts que estan en el package.json si fuera el caso que se necesite.
###  npm install react-scripts --save

Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.
